The insight3
ଅ

One button. Six capabilities.

  • 🔊 Read aloud — follow-along highlight, skip / replay
  • 🌐 Translate → Odia — whole page, in place, one-tap undo
  • 📖 Easy Read — officialese → plain language, offline rules
  • 📄 Read documents — OCR scans & PDFs, original + Odia side by side
  • 🎙️ Speak to fill — asks each field aloud; never presses Submit
  • 🧭 Voice command — say a link's name; no dead ends
Integration = one script tag. Sites not integrated? Our browser extension injects it anyway.

Adoption10

Honest today · concrete next

Limits we'll tell you first

  • OCR: printed notices yes — handwriting no
  • STT wants clear speech — so we retry, and show tappable choices instead of guessing
  • The USB bundle ships mock translation (torch doesn't fit); the laptop runs real IndicTrans2

Roadmap — no rewrites, just pilots

  • Pilot: one district portal + one board site
  • Native-speaker polish of the Odia glossary
  • Bhashini as an alternate engine backend
  • More languages — the engines already support them; it's configuration
