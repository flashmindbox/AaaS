Step 4 · Four AI services
Speech → textIndicWav2Vec (AI4Bharat) · Odia
Text → speechMMS-TTS (Meta) · Odia, Hindi, English
Translate + Easy ReadIndicTrans2 (AI4Bharat) · our rule engine
Read scanned documentsTesseract OCR · images and PDFs

Example: a citizen taps ଦଲିଲ ପଢ଼ (Read document) on a scanned pension circular

1The widget finds the scans and PDFs on the page and shows their thumbnails
2OCR reads the text off the chosen scan
3Easy Read simplifies it, then IndicTrans2 turns it into Odia, keeping dates and numbers exact
4MMS-TTS reads the Odia aloud, with numbers spoken as Odia words
5The citizen sees the original page and the Odia text side by side, with a highlight that follows the voice
No cloudVoice and documents stay on the government’s own server
Works offlineRuns on one ordinary laptop CPU, with no graphics card
Never diesEvery service has a backup mode, so the button stays alive
Open sourceApache-2.0: no licence fee, and Odisha owns it

Rollout plan: Jajpur → OCAC → Odisha → India

Chart3 / 3
Step 1

Pilot: Jajpur

One district portal and one board site (BSE Odisha)

Step 2

OCAC

One shared server at the state data centre

Step 3

All Odisha

Every department portal

Step 4

India

Other states, in their own languages

What happens

Add one line of code to jajpur.odisha.gov.in and bseodisha.ac.in. Run AaaS on one server.

What it takes

One ordinary server CPU, no rebuild of either site, and no cost to citizens.

How we know it works

Citizens and staff try it; we count use of each tool and collect feedback.

What happens

AaaS runs once at OCAC. Each department gets its own API key and usage report.

What it takes

One install serves every portal. Data stays inside the state data centre.

How we know it works

The admin console shows use by each department.

What happens

Every department portal adds the line: pensions, scholarships, results, grievances.

What it takes

Fits 5T (Technology, Transparency) and Mo Sarkar. The Chrome extension covers sites that haven’t adopted it yet.

How we know it works

Fewer citizens need a middleman to use online services.

What happens

Other states adopt it, adding Hindi, Bengali, Telugu and other languages.

What it takes

The AI engines already cover 22 Indian languages: add a language, not a new product. Bhashini can be plugged in as an engine.

How we know it works

Open source (Apache-2.0), so any state can adopt it for free.

Portals stay as they areNo redesign; one line of code per site
One server, whole stateShared infrastructure, like UPI for accessibility
Ready todayWorking prototype, tested on real Odisha government sites
