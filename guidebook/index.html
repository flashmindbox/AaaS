How to print & assemble this book

Open each .html file in Chrome or Edge and press Ctrl + P. In the print dialog set Paper = A4, Margins = Default, and turn “Background graphics” ON (so diagrams and colour boxes print). Print chapters 01→09 in order and clip them together behind this cover.
