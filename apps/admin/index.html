            About this dashboard

            The AaaS Operator Dashboard gives a bird's-eye view of the Accessibility-as-a-Service platform. It is one of the six pillars of the Team SUBARNAREKHA pitch at Smart Odisha Hackathon '25:

            1. Speech-to-Text — Odia-first, with Hindi + English
            2. Text-to-Speech + Screen Reader — drop-in widget
            3. Accessibility API Gateway — this platform
            4. Language Translation — IndicTrans2, corpus fallback
            5. Accessible Exam Module — see /exam/
            6. Admin Dashboard — this page

            Meta MMS-TTS is the single TTS engine — Odia, Hindi, and English share the same VITS family, so there is no browser-voice fallback and no second engine to babysit. If translation is down, the widget still reads the source language; the admin API runs against an in-memory tenant store so the demo never depends on Postgres being up.
