How to demo

  1. Open any tenant site above.
  2. Click the circular ଅ button in the lower-right corner. It opens the AaaS widget.
  3. Hit "Read this page" — Meta MMS-TTS speaks the visible content (Odia, Hindi, or English). If the gateway is offline, the widget shows an error instead of speaking — there is no browser-voice fallback.
  4. Pick a language (Auto / Odia / Hindi / English). Content in another language is translated through the gateway before synthesis.
  5. Hold 🎙 Record to speak into the microphone — the gateway returns a transcript. Demo sites that listen for the aaas-transcript event consume it directly to fill form fields.

Endpoint reference: OpenAPI · Health · Admin

Odia-first by design. Hindi + English supported as fallbacks.
