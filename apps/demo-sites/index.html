How to demo

  1. Open a tenant site — the SSEPD flagship exercises everything on one page.
  2. Click the ଅ button in the lower-right corner — six tiles, Odia labels first.
  3. ପଢ଼ି ଶୁଣାଅ · Read aloud — the page speaks in Odia with a follow-along highlight; ⏮/⏭ skip and replay.
  4. ଅନୁବାଦ · Translate then ସହଜ ପଢ଼ା · Easy Read — whole-page Odia, then plain language. Both undo with ↺.
  5. ଦଲିଲ ପଢ଼ · Read document — pick a scanned notice or PDF; the original and the Odia text appear side by side while it reads aloud.
  6. କହି ଲେଖ · Speak to fill on any application form — it asks for each field aloud and never presses Submit.
  7. କହି ଚଲାଅ · Voice command — say a link's name ("ପେନସନ", "କଣ୍ଟାକ୍ଟ"); unsure matches become tappable choices.
  8. Reading comfort — OpenDyslexic "Comfortable letters", the reading ruler, and hover-to-speak.

Endpoint reference: OpenAPI · Health · Operator console

Odia-first by design. Hindi + English supported as fallbacks. Everything runs on-prem — no cloud calls.
