DEMO RUN-ORDER  (about 6 minutes)
---------------------------------
  1. THE PROBLEM (30 s)
     Government sites are in English, visually heavy, and full of
     scanned PDFs - hard for elderly, low-literacy and disabled citizens.

  2. ONE SCRIPT TAG ON A GOVT SITE  (demo: SSEPD Odisha)
     Click  ଅ
     [ ] Read aloud      - page is read in Odia (starts in ~3 s)
     [ ] Translate       - whole page turns into Odia (~8 s);  ↺ undoes
     [ ] Easy Read       - legal wording becomes plain words
     [ ] Read document   - pick the UDID camp PDF: scan on the left,
                           Odia on the right, read aloud
     [ ] Speak to fill   - scroll to the pension form, answer by voice

  3. ANY REAL WEBSITE, NO SITE CHANGE (browser extension)
     [ ] odisha.gov.in     -> ଅ -> Read aloud (Odia voice)
     [ ] bseodisha.ac.in   -> ଅ -> Read document -> pick the
         "NOTIFICATION FOR ... OSSTET" PDF  (real scanned notice)
     [ ] odisha.gov.in     -> ଅ -> Voice command -> say "read page"

  4. THE PLATFORM (admin console)
     [ ] Numbers moved while you demoed: requests, tenants, latency
     [ ] Tenants table: one gateway serves a district, a university,
         an exam board, a department, a hospital, a central portal
     [ ] "Onboard a website": create a tenant live, copy the one-line
         snippet - that is the entire integration
     [ ] API playground: press Send on Translate / Speech

  5. CLOSE
     Open-source Indian models (AI4Bharat IndicTrans2 + IndicWav2Vec,
     Meta MMS voices), runs fully offline on a laptop or on our own
     server - no third-party AI APIs, privacy policy live.


AVOID ON STAGE
--------------
  - india.gov.in for voice input: that site blocks the microphone.
  - Translating very long pages live (Wikipedia takes 1-3 minutes).
    Demo sites translate in seconds.
  - Crooked or handwritten scans: OCR garbles handwriting.


IF SOMETHING GOES WRONG
-----------------------
  Button does nothing      -> reload the page (F5), click  ଅ  again.
  Online site not loading  -> switch to the Offline addresses.
  Offline services down    -> STOP-DEMO.bat, then START-DEMO.bat (1 min).
  Read aloud slow on a real site (first time) -> it is loading the
      in-browser voice once; the next page is faster.
  Admin shows "unreachable" -> you typed the password in the address;
      open https://168-144-216-83.sslip.io/admin/ plainly.
