# packages/

Shared libraries consumed by apps and services.

| Package           | Purpose                                               |
| ----------------- | ----------------------------------------------------- |
| `@aaas/config`    | Shared ESLint, TypeScript, Prettier configs           |
| `@aaas/ui`        | Accessible design system (tokens + Radix primitives)  |
| `@aaas/a11y-test` | WCAG 2.2 AA automated test harness (axe + Playwright) |

Future: `@aaas/sdk-web`, `@aaas/sdk-rn`, `@aaas/i18n`, `@aaas/telemetry`.
